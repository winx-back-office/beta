ภาพรวมและออเดอร์ Dashboard & Orders

🏠 Dashboard — ภาพรวม

/
แสดงข้อมูล
  • ยอดขายรวม (Total Revenue)
  • รับชำระแล้ว (Amount Received)
  • ยอดคงค้าง (Outstanding Balance)
  • จำนวนงานในคิวออกแบบ
  • จำนวนงานในคิวผลิต
  • ออเดอร์ล่าสุด 5 รายการ
ฟังก์ชั่น
  • คลิกการ์ดคิวเพื่อไปหน้าคิว
  • ลิงก์ "ดูทั้งหมด" → หน้าออเดอร์
  • คำนวณยอดเงินจากออเดอร์ทั้งหมด

📋 รายการออเดอร์

/orders
แสดงข้อมูล
  • ตารางออเดอร์: ID, วันเริ่ม, ทีม, ประเภท, ทรงเสื้อ, จำนวน, ยอดรวม, มัดจำ, คงค้าง
  • จุดสี (Color dot) ระบุสีออเดอร์
  • Tooltip hover: ทรงเสื้อ / ผ้า / ปก
  • Badge แจ้งเตือน "ตารางมีการอัปเดต"
ฟังก์ชั่น
  • เพิ่มออเดอร์ใหม่
  • นำเข้าจาก Google Sheets
  • กำหนดสีออเดอร์ (9 สี)
  • แก้ไขวันที่ inline (double-click)
  • ลบออเดอร์ (hover trash icon)
  • คลิกแถวเพื่อดูรายละเอียด
Modal / Popup
  • Modal เพิ่มออเดอร์: เลือกประเภท, ทีม, วันที่, แพ็กเกจ, ราคา, ต้นทุน, มัดจำ
  • Modal นำเข้า Sheets: 2 แท็บ (ตารางผลิต / หลายออเดอร์)

🔍 รายละเอียดออเดอร์

/orders/[id]
แสดงข้อมูล (คอลัมน์ซ้าย)
  • ข้อมูลออเดอร์: ทีม, วันเริ่ม, ทรงเสื้อ, ผ้า, ปก
  • การเงิน: ราคา, จำนวน, ค่าส่ง, ค่าบริการ, VAT, ยอดรวม, มัดจำ, คงค้าง
แสดงข้อมูล (คอลัมน์ขวา)
  • กำไรประมาณการ
  • ต้นทุนต่อตัว (ผ้า, กระดาษ, หมึก, ตัด, เย็บ, อื่นๆ)
  • ตารางสั่งผลิต: รายชื่อผู้เล่น, การกระจายไซส์, ติ๊กรับ
ฟังก์ชั่น
  • แก้ไขข้อมูลออเดอร์ (toggle edit mode)
  • สลับ VAT on/off
  • สลับต้นทุนแบบรายหมวด / override
  • ลิงก์ไปยังตารางผลิต
  • ปุ่ม "ส่งลูกค้า" (screenshot สรุปการเงิน)
  • คำนวณราคาอัตโนมัติตามทรงเสื้อ/ผ้า/ปก/จำนวน
  • แจ้งเตือนและซิงค์จำนวนถ้าไม่ตรงกับตาราง

ระบบคิว Queue Management

🎨 คิวออกแบบ

/queue/design
แสดงข้อมูล
  • Kanban 5 คอลัมน์: รอออกแบบ → กำลังออกแบบ → รอแก้ไข → รออนุมัติ → เสร็จสิ้น
  • การ์ดแสดง: ชื่อทีม, ทรงเสื้อ, วันเริ่ม
ฟังก์ชั่น
  • ลาก-วางการ์ดระหว่างคอลัมน์
  • จัดเรียงคอลัมน์ด้วยการลาก
  • เพิ่มงานเข้าคิว
  • จุดสีบอกสถานะ

🏭 คิวผลิต

/queue/production
10 สถานะในสายการผลิต
  • รอสรุปงาน → เข้าแพทเทิร์น → วางไซส์
  • พิมพ์ → ตัดแพทเทิร์น → รอส่ง-เย็บ
  • กำลังเย็บ → แพ็คสินค้า → เตรียมจัดส่ง → จัดส่งเรียบร้อย
ฟังก์ชั่น
  • ลาก-วางการ์ดระหว่างสถานะ
  • จัดการคอลัมน์: เพิ่ม/ลบ/แก้ชื่อ/เปลี่ยนสี
  • Modal เพิ่มงาน: เลือกออเดอร์ + คอลัมน์เป้าหมาย
  • โหลดภาพตารางผลิตจาก API อัตโนมัติ

ตารางสั่งผลิต Production Tables

📂 รายการตารางผลิต

/production-tables
แสดงข้อมูล
  • การ์ดออเดอร์ที่มีตารางผลิต
  • ชื่อทีม, ID, ประเภท, ทรงเสื้อ, ผ้า, ปก, สถานะ, วันเริ่ม, จำนวนตัว
ฟังก์ชั่น
  • คลิกเพื่อเปิดตารางผลิต

✏️ แก้ไขตารางผลิต

/production-tables/[id]
แสดงข้อมูล
  • ตารางผู้เล่น: ชื่อ, หมายเลข, ไซส์, หมายเหตุ, สถานะติ๊ก
  • คอลัมน์ไซส์ตามทรงเสื้อ (SS–Special)
  • สรุปจำนวนแต่ละไซส์ + ยอดรวม
  • ผ้า / ปกในส่วนหัว
ฟังก์ชั่น
  • เพิ่ม / แก้ไข / ลบแถวผู้เล่น
  • ติ๊กรับสินค้า (check-off)
  • อัปโหลดภาพ (หลายภาพ, ตั้งภาพหลัก)
  • Auto-save เมื่อมีการเปลี่ยนแปลง
  • แจ้งเตือนก่อนออกเมื่อยังไม่ได้บันทึก

ข้อมูลหลัก Master Data

👕 ข้อมูลทรงเสื้อ

/shirt-styles
แสดงข้อมูล
  • ราคาตามช่วงจำนวน (Pricing tiers) vs ผ้าแต่ละชนิด
  • รายการปก (Collar): ชื่อ, ราคาเพิ่ม, จำนวนชิ้นแพทเทิร์น
  • รายการผ้า: ชื่อ, ราคาเพิ่ม
ฟังก์ชั่น
  • เพิ่มทรงเสื้อใหม่
  • Modal แก้ไข: ชื่อ, ช่วงราคา, ปก, ผ้า
  • เพิ่ม/ลบปกและผ้าจาก master list

🧵 ข้อมูลเนื้อผ้า

/fabrics
แสดงข้อมูล
  • หมวดผ้า 4 ประเภท: เรียบ, ทอพิเศษ, วอร์มพิเศษ, ร่ม
  • Variant chips ในแต่ละหมวด
ฟังก์ชั่น
  • เพิ่ม variant ใหม่ในแต่ละหมวด
  • ลบ variant (กดปุ่ม X)
  • Auto-save ทุกครั้งที่แก้ไข

🔎 ติดตามสถานะ (ลูกค้า)

/track & /track/[id]
แสดงข้อมูล
  • ค้นหาด้วย Order ID หรือชื่อทีม
  • สถานะคิวออกแบบ + คิวผลิต (พร้อมสี)
  • สรุปการเงิน: ยอดรวม, มัดจำ, คงค้าง
  • ลิงก์ตารางผลิต (ถ้ามี)
ฟังก์ชั่น
  • ค้นหา (กดปุ่มหรือ Enter)
  • ไม่พบ → แสดงข้อความแจ้ง
